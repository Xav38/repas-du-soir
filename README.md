# Repas du soir

Repertoire de cuisine familial : 38 plats sur quatre saisons, concu pour qu'un plat
decide a midi soit cuisinable le soir meme, sans passer au magasin.

Application autonome : un seul fichier HTML, aucune dependance, aucun build.
Ouvrir `index.html` dans un navigateur suffit.

## Principes

- Les durees affichees sont des temps reels, prechauffage du four et montee en
  pression du Cookeo compris.
- Chaque fiche indique ce qu'il faut faire a midi, ou signale qu'il n'y a rien a faire.
- Les valeurs nutritionnelles sont estimees a partir des quantites de chaque recette.
- Le garde-manger liste ce qui permet de ne rien acheter le jour meme.
